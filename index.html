kameo-nx web installer

Builds the Nintendo Switch package of Kameo: Elements of Power from your own copy. Everything runs in this browser: nothing is uploaded.

version 1.0.1

1. Choose your game

Your Xbox 360 disc (NTSC-U or PAL) as an .iso, or the folder it was extracted to (with default.xex and the .lvl files in it).

Nothing chosen yet.

2. Choose title update 2 (and the DLC)

kameo-nx is the updated game: choose title update 2's package for your disc (NTSC-U: TU_16L61UI_0000000000000.00000000000G1, inside the update's folder 6C8AE566; PAL: TU_16L61UI_000000K000000.00000000000G5, folder 45BB5521). Add the DLC packs at the same time if you have them: the Add-On, Design-A-Skin, Power and Winter Warrior packs. All are read in place.

Nothing chosen yet.

3. Create the package

Who compiles the shaders?

Either way the page first makes the game's shaders from your files. The zip then downloads while it is written (about 6 GB).

4. Copy it to the Switch

  1. Extract kameo-nx.zip to the root of the SD card: it makes switch/kameo-nx/.
  2. In Sphaira, find Kameo: Elements of Power, press X to open Options and choose Install Forwarder. Make sure Address Space is set to 39-bit, choose Create Forwarder, then start the game from the Home Screen. This lets the game use all four CPU cores, which it cannot do through a title takeover. The first start sets this up; from the second start on the game runs on four cores.
  3. Settings are in switch/kameo-nx/kameo.toml.
